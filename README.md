# competix-landing

Landing page for Competix, a Chrome extension with market analysis for Mercado Libre sellers.

Static site (HTML + CSS, no build step), served with GitHub Pages.

- `index.html`: product, features, pricing, FAQ
- `privacidad.html`, `reembolsos.html`, `terminos.html`: legal pages required by Lemon Squeezy and the Chrome Web Store

Before going live, replace every `CORREO_DE_CONTACTO` with the support email.
